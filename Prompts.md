# ShopZone Project Prompts

This file contains the main development prompts and technical doubt prompts used for building and improving the ShopZone React e-commerce SPA project.

The prompts are written in a professional way and focus on understanding project logic, routing concepts, state management, API handling, and user flow.

---

## 1. Project Understanding Prompt

How can I structure a React single page e-commerce application where users can browse products, view individual product details, manage a shopping cart, and move between pages without refreshing the browser?

---

## 2. Routing Architecture Prompt

## 3. Static Route Concept Prompt
